你打开一个跨链页面，想把 10 个 CCIP-BnM 从 Sepolia 跨到 Fuji。授权那一步已经做完了，可点下“发送”之前，页面又提示你：钱包里的 LINK 不够，先去领一点 LINK。

你愣了一下：我跨的是 CCIP-BnM，Gas 费不是用 ETH 付吗？为什么还要 LINK？LINK 不是一个可以买卖的 Token 吗，怎么变成“过路费”了？

**跨链这件事，到底要付几笔钱？LINK 在里面，到底扮演了什么角色？**

简单来说，跨链不是一条链上的普通转账，它是一次“跨国快递”：有人要在源链上收件、有人要在两条链之间验证这单货是真的、有人要在目标链上送货上门。**这些活不是免费的，LINK 就是付给这套系统的一张通用“饭票”。** 这篇文章，就把这张饭票从头到尾讲清楚。

> 💡 **先说清楚**：本文只讲 CCIP 跨链手续费的原理和测试网操作，不教你操作任何真实资产，也不推荐你去买任何 Token，更不预测 LINK 的价格。**本文是知识科普，不是投资建议。** 全文只在测试网操作，先在测试网练手，不要用真实资产做实验。

## 一、跨链不是免费的：谁在替你干活？

先想一个生活里的场景：你从北京寄一个包裹到上海，要付快递费。这笔快递费不是付给某一个人的，它要分给好几个环节：收件的快递员、负责分拣的中转站、开长途卡车的司机、上海那边送货上门的人。任何一个环节没人干活，包裹就到不了。

跨链也是一样。一笔从 Sepolia 到 Fuji 的跨链交易，背后至少有四拨人在干活：

| 干活的人 | 在干什么 | 打个比方 |
|---|---|---|
| 源链上的 CCIP 路由器和 Token 池 | 收下你的 Token，把它锁起来或者烧掉 | 北京的收件点 |
| 验证网络（CCV / 原来的 DON 和 RMN） | 验证这笔跨链消息是真的、没有被篡改 | 中转站的安检和验货 |
| 目标链上的执行器（Executor） | 在目标链上提交交易、执行接收逻辑、把 Token 发给你 | 上海的派送员 |
| CCIP 协议本身 | 维护整条“线路”和基础设施 | 快递公司总部 |

第 22 篇讲 CCIP 架构的时候提到过，CCIP 的消息要经过多个独立节点运营商验证（2026 年的 CCIP 2.0 里，每条线路默认由 16 个独立节点运营商组成的验证网络把关，要达到多数签名才放行），还有一个独立的风险管理网络可以在发现异常时暂停某条线路。这些节点不是在做慈善——它们提供算力、跑节点、承担风险，理应拿到报酬。

**所以跨链的手续费，本质上是“人工费 + 场地费”：付给替你干活的人，和维护这条线路的协议。** LINK 就是用来付这笔钱的币。

### 一笔跨链，要付几笔钱？

新手最容易搞混的一点是：跨链的时候，钱包里其实要准备三种不同用途的钱：

```
你发起一笔跨链，要付的钱分三类：

① 源链 Gas 费（用 ETH / AVAX 等源链原生币付）
    —— 你在源链上发交易，矿工/验证者收的钱
② CCIP 跨链手续费（用 LINK 或源链原生币付）
    —— 付给 CCIP 系统的钱，包含目标链执行、验证、协议费
③ 你要跨过去的 Token 本身（比如 10 个 CCIP-BnM）
    —— 这是你要寄的“包裹”，不是手续费
```

① 和 ② 是两笔不同的钱，别把它们混在一起。① 是任何链上交易都要付的 Gas，② 才是跨链特有的费用。很多人第一次跨链失败，就是因为钱包里只有 ETH、没有 LINK：① 够付，② 付不出来，交易直接被拒绝。

## 二、手续费到底由哪几部分组成？

Chainlink 官方文档（2026 年 11 月 13 日发布的 CCIP 2.0 费用说明）把一笔 CCIP 消息的费用拆成了四部分。总数就是这四部分加起来，在你发消息的那一刻算出来。

| 费用 | 付给谁 | 付的是什么钱 |
|---|---|---|
| 执行费（Executor Fee） | 目标链上的执行器 | 目标链上执行交易的 Gas 费，外加执行器可能收的一笔固定费用 |
| 验证费（CCV Fee） | 跨链验证器 | 验证消息、生成证明的费用；Chainlink 官方默认的验证器目前不收固定费用 |
| Token 池费（Token Pool Fee） | Token 池的发行方 | 转移某个 Token 的特定成本和风险调整；可能是固定美元费用，也可能是按转账金额收一定比例（从转的 Token 里扣） |
| CCIP 网络费（协议费） | CCIP 协议本身 | 使用 CCIP 系统的协议级服务费，按线路收固定美元金额 |

### 哪一部分是大头？

对一次普通的 Token 跨链来说，**执行费通常是大头**，因为它里面包含目标链上真正要烧掉的 Gas。官方文档给出的公式是：

```
目标链执行费 = 目标链总 Gas × 目标链 Gas 价
目标链总 Gas = 你设的 gasLimit + 固定开销 + 验证 Gas
              + Token 转移 Gas + 每字节数据 Gas × 消息大小
```

看这个公式你就能明白，手续费为什么每次都不一样：目标链 Gas 价在变、你要跨的 Token 数量和消息大小在变、接收方合约要执行的逻辑（gasLimit）也在变。**所以不要背某个具体的数字，每次跨链之前，先问价。** 怎么问价，第五节手把手讲。

### 协议费：用 LINK 付，比用别的币便宜

四部分里面，协议费（CCIP 网络费）有一张公开的价目表，按源链和目标链的组合定价。下面这张是 Chainlink 官方文档 2026 年 11 月 13 日更新的版本，Token 跨链的部分：

| 源链 → 目标链 | 用 LINK 付 | 用别的币付 |
|---|---|---|
| Ethereum → 非 Ethereum（不含 Solana） | $0.45 | $0.50 |
| Ethereum → Solana | $0.54 | $0.60 |
| 非 Ethereum → Solana | $0.315 | $0.35 |
| 非 Ethereum（不含 Solana）→ Ethereum | $1.35 | $1.50 |
| 非 Ethereum → 非 Ethereum（不含 Solana） | $0.225 | $0.25 |

只发消息、不转 Token 的纯消息跨链也是一样的规律：比如非 Ethereum 链之间发消息，用 LINK 付是 $0.09，用别的币付是 $0.10。

**看出来了吗？用 LINK 付协议费，比用别的币便宜一成。** 这不是巧合，这是 Chainlink 官方定价里写明的规则：用非 LINK 的币付协议费，要加收 10% 的附加费。换句话说，LINK 是 CCIP 的“会员价”，别的币是“原价”。

## 三、为什么偏偏是 LINK？

到这里你可能会问：为什么是 LINK？为什么 Chainlink 不直接收 ETH、收 USDC，非要搞一个自己的 Token？

### 原因一：LINK 是 Chainlink 全家服务的通用“饭票”

CCIP 不是 Chainlink 唯一的服务。在这个系列后面，你还会学到 Chainlink VRF（可验证随机数，第 42 篇）、Chainlink Functions（让智能合约访问互联网，第 45 篇）、Chainlink Automation（让合约自动执行，第 33 篇）。**这些服务，付费的币都是 LINK。**

打个比方：LINK 就像一个游乐园的通用代币。你进了 Chainlink 这个游乐园，不管是玩过山车（CCIP 跨链）、抽奖机（VRF 随机数），还是自动售货机（Functions 调 API），门口收的都是同一种代币。你不用每玩一个项目就去换一种币，一种币走遍全园。

对开发者来说，这很方便：钱包里备一点 LINK，Chainlink 的服务基本都能用。对 Chainlink 来说，这也很合理：所有服务的收入，都沉淀到同一种 Token 上。

### 原因二：跨链要给很多条链上的人发工资，得有一种大家都认的币

想一想，CCIP 现在连接了几十条链（2026 年 10 月的行业盘点里，CCIP 已连接 77 条主网）。一条从 Sepolia 到 Fuji 的跨链，背后是运行在不同链上的节点在干活。如果每条链都用自己的原生币结算，账会算得一团糟：ETH、AVAX、MATIC、SOL……每种币的价格都在变，节点运营商今天收 ETH、明天收 AVAX，根本没法统一记账和分钱。

**LINK 解决的就是这个问题：不管源链是 Ethereum 还是 Avalanche，不管目标链是哪条，手续费都可以用同一种币来计价和结算。** 这就像国际贸易里大家都用美元结算一样，不是因为美元是哪一国的货币，而是因为它是一个大家都认的中间单位。

官方文档里也写得很直白：CCIP 支持用 LINK 和其他资产（包括各链原生币及其包装版）付费，目的就是降低使用门槛、让 CCIP 能扩展到更多链。但 LINK 始终是那个默认的、也是最便宜的选项。

### 原因三：费用要“一次付清”，LINK 让这件事变得简单

CCIP 有一个很重要的设计，叫“Gas 锁定付费”：**你在源链上一次把跨链手续费付清，CCIP 就负责把消息送到目标链并执行好，哪怕目标链的 Gas 价中途突然涨了，也不用你再补钱。**

这个设计能成立，前提是 CCIP 在你付钱的那一刻，就能把“目标链执行大概要花多少钱”算清楚、锁定下来。这需要一套统一的计价单位：先把目标链的 Gas 成本折算成美元，再按 LINK 的价格换算成 LINK。LINK 作为 Chainlink 自己的计价币，在这个换算里是最直接的。

所以你看，LINK 在跨链里不是一个“顺便收的币”，它是整个计费、报价、结算体系的默认单位。

### 补充：LINK 不只是手续费，它也是网络收入的沉淀方式

还有一点值得知道，但不用深究：Chainlink 在 2025 年 8 月推出了 Chainlink Reserve（储备金），会把 CCIP、Data Streams 等服务的网络收入定期换成 LINK、长期持有。也就是说，你付的跨链手续费，最终有一部分会变成 LINK 回到 Chainlink 的储备里。

这件事对你写跨链代码没有直接影响，但它解释了 LINK 的价值是从哪来的：**LINK 的需求，一部分就来自 CCIP 这类服务真实产生的手续费。** 不是凭空印出来的。

## 四、一定要用 LINK 付吗？也可以用 ETH

说到这里，必须把一个最容易误解的点讲清楚：**跨链手续费，不是一定要用 LINK 付。**

### 两种付费方式，怎么选？

官方文档明确写着：CCIP 支持用 LINK 付，也支持用源链的原生 Gas 币（比如 Sepolia 上的 ETH、Fuji 上的 AVAX）或者它们的包装版付。选哪种，取决于你在发消息时传的 `feeToken` 参数：

| 付费方式 | feeToken 参数怎么传 | 钱包里要准备什么 | 协议费 |
|---|---|---|---|
| 用 LINK 付 | 传 LINK 的合约地址 | LINK 余额 + 事先授权给路由器 | 便宜一成（会员价） |
| 用原生币付 | 传 `address(0)`（表示原生币） | 源链原生币余额，随交易一起发过去 | 贵一成（原价） |

用原生币付的时候，你不用提前授权——因为原生币是随交易一起发过去的（`msg.value`），不像 ERC20 那样要先 `approve`。但代价是协议费要多付 10%。

**怎么选，看你的实际情况：**

- 你是开发者，经常要跨链、或者要给合约长期供 LINK：用 LINK 付，长期下来更便宜，而且 Chainlink 的其他服务（VRF、Functions）也要用 LINK，一次备齐。
- 你只是偶尔跨一次、钱包里正好有 ETH、不想再去领 LINK：用原生币付，贵一点，但省事。
- 你在用一些跨链应用（比如 Transporter 这类基于 CCIP 的桥）：很多应用直接帮你用原生币结算，你根本感觉不到 LINK 的存在——但底层的 CCIP 费用，应用还是替你付了的。

### 一个经常犯的错：以为“不用 LINK”就等于“免费”

这是经常犯的错：听说“可以用 ETH 付”，就以为跨链不要 LINK、甚至不要手续费了。其实不是。用 ETH 付，只是换了一种币付同一笔钱，手续费一分都不会少，反而协议费那部分还要多付 10%。

**记住：跨链手续费是省不掉的，只能选“用什么币付”和“付多付少”。**

## 五、动手：先问价，再付钱

理论讲完了，这一节动手走一遍。全部用测试网，不花真钱。

### 准备：测试网的 LINK 从哪来？

测试网的 LINK 不用买，从 Chainlink 的水龙头领就行：faucets.chain.link。领之前，先确认你的钱包已经切到了对应的测试网（第 24 篇讲过怎么切网络）。

LINK 在每条链上的合约地址都不一样，动手之前，先去 Chainlink 官方的 LINK Token 合约页面核对一次，不要从聊天群、论坛帖子里复制地址：

| 测试网 | Chain ID | LINK 合约地址 |
|---|---|---|
| Ethereum Sepolia | 11155111 | `0x779877A7B0D9E8603169DdbD7836e478b4624789` |
| Avalanche Fuji | 43113 | `0x0b9d5D9136855f6FEc3c0993feE6E9CE8a297846` |

LINK 的小数位数是 18 位。领到之后，在 MetaMask 里添加上面这个合约地址，就能看到余额了。

### 第 1 步：先用 getFee() 问价

CCIP 的路由器提供了一个 `getFee()` 函数：你把目标链、要发的消息、要转的 Token 告诉它，它会先告诉你这笔跨链大概要收多少手续费。**先问价，再授权、再发送，是比较稳妥的顺序。** 官方教程也是这个顺序。

```
router.getFee(
    目标链的 Chain Selector,   // 比如 Fuji 的 Chain Selector
    要发的跨链消息             // 包括接收地址、要转的 Token、feeToken 等
)
    ↓ 返回一个数字：这次跨链要收多少手续费（以 feeToken 计价）
```

问价本身是一个只读调用，不花 Gas。你可以多问几次、换不同的参数问：比如把 `feeToken` 从 LINK 换成原生币，对比一下两种付费方式的报价；或者把 `gasLimit` 调大调小，看看手续费跟着怎么变。

### 第 2 步：用 LINK 付，要先授权

如果选择用 LINK 付手续费，LINK 是 ERC20 Token，路由器想拿你的 LINK，得先经过你授权——就是上一篇讲的 `approve()`：

```
① 你调用 LINK 合约的 approve(路由器地址, 手续费金额)
    ↓ 付一笔源链 Gas 费
② 再调用 ccipSend() 发跨链消息
    ↓ 路由器用 transferFrom() 从你钱包里扣掉 LINK 手续费
    ↓ 同时把你要跨的 Token 也收走
```

注意，第①步授权的是 LINK，第②步路由器扣的也是 LINK。上一篇讲过，跨链要跨的 Token（比如 CCIP-BnM）也要单独授权一次。所以一次完整的跨链，钱包里可能要做两次授权：**一次授权要跨的 Token，一次授权付手续费的 LINK。** 再加上真正的发送交易，一共要确认三次。这就是为什么你第一次跨链的时候，钱包会弹出来好几次确认框——不是出 bug 了，是每一步都在干不同的事。

### 第 3 步：用原生币付，就不用授权 LINK

如果选择用原生币付，流程就少一步：

```
① 调用 getFee() 问价（以原生币计价）
    ↓
② 调用 ccipSend()，同时把原生币手续费一起发过去（msg.value）
    ↓ 不用提前授权，因为原生币是随交易一起转的
```

少一次授权，就少付一笔源链 Gas 费、少点一次确认框。这是用原生币付唯一的好处——但协议费贵一成，长期算下来，LINK 还是更便宜。

### 一个细节：gasLimit 设多少，手续费就跟着变多少

`getFee()` 问价的时候，有一个参数特别影响价格：`gasLimit`，也就是你允许 CCIP 在目标链上最多花多少 Gas 去执行接收方的逻辑（`ccipReceive()`）。

- 设得太低：目标链执行到一半 Gas 不够，执行失败，还得手动再执行一次。
- 设得太高：用不完的 Gas **不退钱**。官方文档明确写着：你按设定的额度付费，没用完的部分不退还。

**所以 gasLimit 不是越大越保险，而是“够用就好”。** 官方文档的建议是：先在接近真实的条件下测试接收方大概要花多少 Gas，留一点合理的余量，再写进参数里。纯 Token 转账、不调用目标链合约逻辑的时候，gasLimit 可以设成 0。

## 六、钱包里要准备哪几种币？一张清单

把前面几节串起来，跨链之前，钱包里要准备的东西其实就三样。出发之前，对着这张清单打勾：

| 要准备的 | 用来干什么 | 从哪来 |
|---|---|---|
| 源链原生币（ETH / AVAX） | 付源链 Gas 费；如果选原生币付费，也用来付 CCIP 手续费 | 测试网水龙头 |
| LINK | 付 CCIP 跨链手续费（推荐方式，更便宜） | Chainlink 水龙头 faucets.chain.link |
| 要跨的 Token（比如 CCIP-BnM） | 这次要寄过去的“包裹” | Chainlink 水龙头 |

**三样缺了任何一样，跨链都会失败，而且失败的方式各不相同：**

- 缺源链原生币：交易发都发不出去，钱包直接提示余额不足。
- 缺 LINK（又选了 LINK 付费）：`getFee()` 能问价，但 `ccipSend()` 会失败，因为路由器扣不到手续费。
- 缺要跨的 Token：授权那一步就过不去，`transferFrom()` 会因为余额不足被拒绝。

下次跨链之前，先看一眼钱包里这三样的余额，再动手，能省掉很多来回折腾。

## 七、新手最容易踩的五个坑

前面几节讲的都是“怎么做对”，这一节讲“怎么做错”。这五个坑，都是新手真实踩过的。

### 坑 1：钱包里只有 ETH，没有 LINK，跨链发不出去

这是最容易出现的问题。第一次跨链的人，往往只准备了 ETH（付 Gas）和要跨的 Token，完全没想到还要 LINK。点发送，交易失败，报错信息还看不懂。

**怎么避开：动手之前，先去水龙头领一点测试网 LINK。领多少？先 `getFee()` 问一次价，按报价多领一点就行。**

### 坑 2：LINK 领到了，却忘了授权给路由器

LINK 在钱包里，不等于路由器能拿走它。ERC20 的规矩上一篇刚讲过：合约想动你的币，必须先授权。LINK 也一样。

**怎么避开：用 LINK 付费的时候，记得先 `approve()` LINK 给 CCIP 路由器（或者给你的跨链合约），额度至少要覆盖 `getFee()` 问到的价。授权完再发 `ccipSend()`。**

### 坑 3：以为手续费是固定价，照着别人的数字抄

“别人跨一次花了 0.5 个 LINK，我也准备 0.5 个”，这是经常犯的错。手续费跟目标链、目标链 Gas 价、消息大小、gasLimit 都有关系，别人那次的报价，到你这儿可能完全不一样。

**怎么避开：每次跨链之前，都自己调一次 `getFee()` 问价。不要抄别人的数字，也不要抄上一次的数字。**

### 坑 4：gasLimit 设得太大，白白多付钱

怕目标链执行失败，就把 gasLimit 设成一个很大的数字。结果执行只用了其中一小部分，剩下的 Gas 费不退，白白多付了手续费。

**怎么避开：gasLimit 按实际需要估算，留合理余量就行。纯 Token 转账不用调接收方逻辑，设成 0。**

### 坑 5：只看 LINK 的价格，不看手续费到底是多少美元

LINK 的价格每天都在变，`getFee()` 返回的是 LINK 的数量。0.1 个 LINK 今天值多少钱、明天值多少钱，完全是两回事。

**怎么避开：问价的时候，把 LINK 的数量换算成美元看一眼。官方文档的协议费价目表本身就是按美元标的（比如跨到 Ethereum 用 LINK 付是 $1.35），这就是为了让你不管 LINK 价格怎么变，都能对成本有个稳定的概念。**

> ⚠️ **风险提示**：跨链手续费涉及真实资产的支出，不同链、不同方向、不同时间的费用差异很大。本文只讲原理和测试网操作，不构成任何操作建议或投资建议。实际操作前请自行核实官方文档，先在测试网（比如 Sepolia、Fuji）上完整走一遍流程，再考虑主网——而且永远只用你输得起的金额。

## 总结

1. **跨链不是免费的。** 一笔跨链背后有四拨人在干活：源链收 Token、验证网络验消息、目标链执行、协议维护线路。手续费就是付给他们的钱。
2. **手续费由四部分组成：** 执行费（目标链 Gas，通常是大头）、验证费、Token 池费、CCIP 网络费（协议费）。总数在发消息的那一刻算出来，每次都不一样。
3. **LINK 是 CCIP 的默认付费币，也是更便宜的那个。** 协议费的价目表里，用 LINK 付比用别的币便宜一成（比如跨到 Ethereum 是 $1.35 对 $1.50）。LINK 还是 Chainlink 全家服务（VRF、Functions、Automation）的通用付费币。
4. **不是非用 LINK 不可。** 手续费也可以用源链原生币（ETH、AVAX）付，`feeToken` 传 `address(0)` 就行，还省一次授权。但协议费要贵一成，长期用下来 LINK 更划算。
5. **先问价，再付钱。** `getFee()` 问价是只读调用，不花 Gas；问完价再决定用哪种币付、授权多少 LINK，最后才 `ccipSend()`。gasLimit 设大了不退钱，够用就好。
6. **钱包里要备齐三样东西：** 源链原生币（付 Gas）、LINK（付跨链手续费）、要跨的 Token。缺任何一样，跨链都会失败。

下次再有人问你“跨链为什么要 LINK”，你可以直接回答他：

**因为跨链背后有一整套系统在替你干活，验证、执行、维护线路都要花钱，LINK 就是付这笔钱的通用“饭票”——它是 Chainlink 所有服务的默认付费币，用它付还便宜一成。你也可以用 ETH 付，但那只是换了一种币付同一笔钱，手续费一分都不会少。**
