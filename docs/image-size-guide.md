# 界面图片尺寸指南

本文档汇总站点各界面图片槽位的**显示尺寸、构建期生成的产物尺寸、建议准备的原图尺寸**，供替换 / 上传图片时对照。

## 图片的三种存放方式（决定了是否被优化）

| 方式 | 写法示例 | 是否构建期优化 | 说明 |
|---|---|---|---|
| `src/assets` 资产 | `assets/images/banner.avif`（不以 `/` 开头） | ✅ 自动生成多尺寸 + LQIP 占位 | 推荐，构建稍慢 |
| `public` 直连 | `/assets/images/banner.avif`（以 `/` 开头） | ❌ 原样上传 | 体积需自己控制 |
| 远程 URL | `https://example.com/a.jpg` | ❌ 原样外链 | 依赖外链可访问性 |

---

## 1. 站点壁纸（桌面端）

- **配置位置**：`src/config/backgroundWallpaper.ts` → `src.desktop`
- **显示区域**：首页 Banner，宽 100vw、高约 65vh（其他页 45vh / 35vh），`object-fit: cover`
- **构建产物**：`src` 资产方式生成 **1280 / 1920** 两档宽度；`public` 直连则只有原图
- **建议原图**：**≥1920×1080（16:9）**，AVIF/WebP，**单张 ≤ 1MB**
  - 当前使用的 `/assets/random-cover/img-001~005.avif` 已统一压到 **2560×约1435、110–190KB/张**（原图备份在仓库外 `wallpaper-backup/`）

## 2. 站点壁纸（移动端）

- **配置位置**：同上 → `src.mobile`
- **构建产物**：**640 / 828** 两档宽度
- **建议原图**：**≥828 宽**（横竖图均可，cover 裁切）；当前与桌面共用同一组图

## 3. 头像（侧边栏资料卡）

- **配置位置**：`src/config/profileConfig.ts` → `avatar`
- **显示区域**：侧边栏资料卡，卡片宽约 300px
- **构建产物**：`src` 资产方式生成 **350** 宽一档
- **建议原图**：**≥350×350 正方形**（AVIF/WebP/PNG）
  - ⚠️ 当前用的是远程 4K 图（2560×2560，数 MB），侧栏首屏加载偏慢，建议压缩为 350×350 或 512×512 后转存本地

## 4. 头像（动态页横幅右下角 / 每条动态作者栏）

- **显示区域**：横幅右下角 **72×72px**（2x 屏 144px）、动态条目作者栏 **48×48px**
- **构建产物**：**96** 宽一档
- **建议原图**：与侧栏头像同一张即可，**≥192×192 正方形**

## 5. 文章封面图

- **配置位置**：文章 Frontmatter `image: "/assets/xxx.webp"`（或 `image: "api"` 随机图）
- **显示区域**：列表卡片 + 文章详情页顶部
- **构建产物**：`src` 资产方式生成 **828** 宽一档 + LQIP 模糊占位
- **建议原图**：**≥828 宽**，常用 **16:9（如 1600×900）**；避免超过 2560（不会生成更大产物）

## 6. OG 分享图（微信 / Twitter / Discord 卡片）

- **构建产物**：开启 `siteConfig.post.generateOgImages` 后，每篇文章自动生成 **1200×630 PNG**（`/og/<slug>.png`）；未开启时直接使用封面原图
- **建议**：封面原图按 1200×630 以上的 1.91:1 比例准备即可，无需单独制作

## 7. 动态页横幅背景图

- **配置位置**：`src/config/dynamicConfig.ts` → `bannerImage`
- **显示区域**：动态页顶部横幅，宽约 1200px、高 ≥256px（随内容增高），`object-fit: cover`
- **构建产物**：`public` 直连，**不做任何优化**
- **建议原图**：**2560×512 ~ 2560×720**，AVIF/WebP，**≤ 500KB**
- **更换方法**：图片放进 `public/assets/dynamic-banner/`，把路径填到 `bannerImage`；留空显示主题色渐变

## 8. 动态配图（每条动态里的图片）

- **存放方式**：动态 Markdown 里正常写图片语法，图片文件放 `public/assets/...` 或 `src/assets/...`
- **显示区域**：动态卡片内容区，点击可放大查看
- **建议原图**：**1280~1920 宽**，单张 ≤ 500KB（`public` 直连不优化）

## 9. 音乐播放器封面

- **来源**：音乐接口返回的专辑封面（网易云一般为 300×300）
- **显示区域**：侧边栏播放器约 40×40px
- **无需本地准备图片**

## 10. Favicon（站点图标）

- **存放位置**：`public/favicon/`
- **现有尺寸**：32 / 128 / 180 / 192 PNG（`favicon-light-*`、`favicon-dark-*` 明暗两套）+ SVG 源
- **建议源图**：**≥512×512 正方形**，改图标时按上述四档重新导出

## 11. 第三方接口图（无需本地准备）

| 槽位 | 来源 |
|---|---|
| GitHub 仓库卡片 | GitHub API（`scripts/generate-github-card-data.ts` 生成的数据） |
| VNDB / 番组计划 / Bilibili 封面 | 各自接口，构建期可下载缓存到 `public/vndb-covers/` |
| 文章随机封面（`image: "api"`） | `coverImageConfig.randomCoverImage` 配置的 API，建议 API 返回 ≥828 宽 |

## 快速自检清单

- [ ] 桌面壁纸 ≥1920 宽、≤1MB？
- [ ] 头像是否还是 4K 原图？（侧栏用它，建议压到 350×350）
- [ ] `public` 直连的图（壁纸 / 动态横幅 / 动态配图）单张是否 ≤1MB？
- [ ] 文章封面是否 ≥828 宽？（小于会虚）
- [ ] 换 Favicon 是否四档尺寸都更新了？
